# Trilochana Satapathy - Portfolio

Senior Software Engineer portfolio built with modern web technologies.

## About

Portfolio website showcasing 8+ years of experience in full-stack development, data engineering, and backend systems. Specialized in building scalable web applications, data pipelines, and cloud-based solutions.

## Tech Stack

- **Framework:** Next.js 16 (App Router with Turbopack)
- **Language:** TypeScript 5
- **Styling:** Tailwind CSS 3.4
- **UI Components:** Radix UI, ShadCN UI
- **Animations:** Framer Motion
- **Theme:** next-themes for dark/light mode
- **Icons:** React Icons
- **Package Manager:** Bun

## Features

- ⚡ Built with Next.js 16 and Turbopack for blazing-fast development
- 🎨 Modern UI with Tailwind CSS and Framer Motion animations

- 📱 Fully responsive design
- ♿ Accessibility-focused with Radix UI primitives

- 📊 Interactive skills visualization
- 📅 Timeline showcasing work experience and projects
- 💼 Project showcase with detailed information

## Getting Started

### Prerequisites

- Bun (or Node.js 20+)

### Installation

```bash
# Install dependencies
bun install

# Run development server
bun dev

# Build for production
bun run build

# Start production server
bun start
```

Open [http://localhost:3000](http://localhost:3000) to view it in your browser.
